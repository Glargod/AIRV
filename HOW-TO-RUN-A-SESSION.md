# How to Run an AI RV Session

Interactive Dual-Mode Edition
AI Remote Viewing Protocol – April 2026

This document explains exactly how to run a complete session using the two-agent system in the Glargod/AIRV repository.

### Overview
Each session uses two AI agents working together in a structured back-and-forth loop:

- Agent 1 (Viewer) performs the blind remote viewing and sensory work.
- Agent 2 (Guide) provides gentle, unbiased steering probes based only on the Viewer’s raw output.

The entire process stays double-blind until the official reveal step.

### Required Files
- AGENT-1-VIEWER.md
- AGENT-2-GUIDE.md
- README.md

### 1. Preparation
- Choose or create a target. Using one real event plus 3 plausible decoys is recommended for testing.
- Prepare the Guidance Checklist:
  - Presence or Absence of Entities (biological, conscious, or energetic signatures)
  - Viewpoints: close-in tactile to medium gestalt to wide contextual
  - Environmental or Sensory Baseline (terrain, atmosphere, temperature, lighting, ambient sound/smell)
  - Dynamics (motion, stability, flow, rhythm, change over perceived time)
  - Optional Temporal Anchor (blind-safe description only)
- Decide which AI models will play Viewer and Guide roles.

### 2. Start the Session
1. Open two separate chat windows or threads:
   - One dedicated to Agent 1 (Viewer)
   - One dedicated to Agent 2 (Guide)

2. In the Viewer chat, paste the full content of AGENT-1-VIEWER.md at the very beginning.  
   Then send this starting message:

   You are now Agent 1 (Viewer). Begin a blind session for Target XXXXX.

   Guidance Checklist:
   - Presence or Absence of Entities
   - Viewpoints: close-in tactile to medium gestalt to wide contextual
   - Environmental or Sensory Baseline
   - Dynamics
   - Add any optional blind-safe Temporal Anchor here

   Begin Step 2: Initial Blind Acquisition.

3. Let Agent 1 generate its initial impressions, Sensory Gestalt Expansion, and gestalt rankings (1 to 5).

4. Copy only Agent 1’s raw output (from ideogram through ranked gestalts) and paste it into the Guide chat.

5. In the Guide chat, first paste the full content of AGENT-2-GUIDE.md.  
   Then send the pasted Viewer output with this message:

   You are Agent 2 (Guide). Here is the raw output from Agent 1. Generate 1 to 2 gentle steering probes.

6. Copy the Guide’s response (1 to 2 probes) back to the Viewer chat and continue the loop.

7. Repeat the Viewer to Guide to Viewer cycle 1 to 3 times or until the Viewer indicates the signal has stabilized.

### 3. Reveal Phase
When Agent 1 outputs Ready for Reveal, pause both agents.

Provide the full target identity and context only to Agent 1 (Viewer).

Let Agent 1 perform post-reveal matrixing and scoring against the real target plus all decoys.

Optional: Share the reveal with Agent 2 afterward for independent matrixing and comparison.

### 4. Image Prompt Handling
Whenever Agent 1 or Agent 2 triggers an image prompt, copy the full prompt and generate the image using your preferred tool.

Save the generated images with the session ID and gestalt rank.

Add the images or links to your session documentation.

### 5. Session Documentation
For each completed session, save a log that includes:
- Full chat logs from both Agent 1 and Agent 2
- All image prompts and generated images
- Post-reveal scoring matrix
- Any observations or suggested protocol improvements

Recommended filename format:
Session-YYYYMMDD-TargetID-ViewerModel-GuideModel.md

### Best Practices
- Keep Agent 2 strictly blind at all times. Never share any target-related information with the Guide.
- Encourage rich sensory detail in every expansion round (colors, scents, sounds, temperatures, kinesthetics, energetic tang).
- When possible, use different AI models for Viewer and Guide to reduce model-specific bias.
- Run the same target multiple times with different model pairs for stronger comparative data.

### Optional Variations
- Single-model mode: Run both roles in one long thread with clear role switches.
- Triple-blind: Use a third AI as Tasker who handles target creation and reveal timing.
- Image-focused sessions: Request more frequent image prompt triggers.
