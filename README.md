# AIRV – AI Remote Viewing

An open repository for **blind AI-assisted remote viewing** experiments using the AI Remote Viewing Protocol (Temporal Refinement Edition).

## Purpose
- Run disciplined, multi-model blind RV sessions
- Track accuracy, AOL patterns, and temporal performance
- Share raw blind data and post-reveal analysis
- Build a public archive of reproducible RV work with AI

## Current Active Experiment
**Target 3S5I** – Artemis II Orion capsule *Integrity*  
Three-pass temporal remote viewing (with radio silence anchor for Pass 2).

→ See `/sessions/3S5I/`

## Repository Structure
- `sessions/[TARGET]/` — All data for each coordinate set
- `protocol/` — The official protocol
- `templates/` — Ready-to-use templates
- `docs/` — Methodology and guides
