# Can AI Truly Remote View?

An Open, Transparent Experiment in AI-Assisted Remote Viewing

**Repository:** Glargod/AIRV  
**Current Version:** Interactive Dual-Mode Edition – April 2026  
**License:** MIT

### Purpose
This project explores whether large language models can produce meaningful remote viewing data when given a highly structured, blind, and interactive protocol.

We do not claim psychic abilities. We are rigorously testing the boundary between advanced pattern recognition and possible non-local information access using strict blind controls, sensory discipline, and guided interaction.

### Recommended Approach: Interactive Dual-Mode
The current recommended method is the **Interactive Dual-Mode** system:

- **Agent 1 (Viewer)** performs the blind acquisition, ritual ideogram probing, broad sensory sweep, and deepening.
- **Agent 2 (Guide)** provides gentle, dynamic, non-leading steering probes to help build context and prevent gestalt locking.

This back-and-forth approach improves signal depth and reduces early bias compared to single-agent sessions.

### Key Features
- Strict double-blind protocol
- Mandatory broad sensory sweep and ritual ideogram probing
- Mandatory image prompt generation
- Two-tier post-reveal matrixing (direct comparison + standalone signal evaluation)
- Viewer controls when the session ends
- Support for both Dual-Mode (recommended) and Single Viewer Mode

### How to Participate
1. Read `HOW-TO-RUN-A-SESSION.md`
2. Use the two agent files to run sessions (Grok, Claude, Gemini, etc.)
3. Document sessions using the templates
4. Upload your logs, image prompts, and matrixing results
